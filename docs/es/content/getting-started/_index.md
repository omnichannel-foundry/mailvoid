# Primeros pasos

Compila MailVoid, inícialo con una contraseña de administrador conocida, envía un
mensaje e inspecciónalo en la consola.

1. [Instalación](/getting-started/installation/) — compila e instala el binario.
2. [Inicio rápido](/getting-started/quick-start/) — ejecútalo y captura tu primer
   mensaje.
3. [Configuración](/getting-started/configuration/) — todas las variables de
   entorno y flags.
