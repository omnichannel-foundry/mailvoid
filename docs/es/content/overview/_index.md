# Descripción general

MailVoid existe para hacer visible el correo entrante. Apunta cualquier cliente
SMTP, aplicación o suite de pruebas a un listener de MailVoid y cada mensaje se
podrá inspeccionar mediante una consola web cuidada y una API JSON.

El proyecto es deliberadamente pequeño: un proceso, una base de datos embebida,
sin servicios externos y sin un paso de compilación de frontend en tiempo de
ejecución. Todo el sistema es un binario Go más un directorio de datos.

Comienza con [Introducción](/overview/introduction/) para los objetivos de
diseño, luego [Características](/overview/features/) para la lista de
capacidades y [Arquitectura](/overview/architecture/) para ver cómo encajan las
piezas.
